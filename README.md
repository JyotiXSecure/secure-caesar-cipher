## 🔐 Secure Caesar Cipher (Python)

This project is a Python implementation of the Caesar Cipher with a basic secure mode to demonstrate how encryption works, how brute force attacks happen, and how simple protections can reduce risk.

## 📌 What is Caesar Cipher?

Caesar Cipher is one of the oldest encryption techniques where each letter in a message is shifted by a fixed number in the alphabet.

Example (Shift = 3):

HELLO → KHOOR

## 🧠 What this project demonstrates

•Text encryption using Caesar Cipher

•Text decryption using the correct key

•Why Caesar Cipher is vulnerable to brute force

•A secure mode that limits decryption attempts

•This helps understand both attack and defense concepts, which is important in cybersecurity.

## 🛡️ Secure Mode Features

•Only the correct shift key can decrypt the message

•Maximum 3 attempts allowed

•Access is blocked after repeated wrong attempts

•Prevents easy brute force attacks

## ⚠️ Limitations

•Caesar Cipher has a very small key space (26 keys)

•Not secure for real-world applications

•Used only for learning cryptography basics
